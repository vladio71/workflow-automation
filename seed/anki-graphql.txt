What are the 4 resolver arguments and what is each for?	<b>parent</b>: результат рівнем вище; <b>args</b>: аргументи поля, вже приведені до типів; <b>context</b>: один об'єкт на запит (db, loaders, currentUser); <b>info</b>: AST і шлях поля.	graphql drill01
What is the default resolver?	Якщо резолвера для поля немає, GraphQL повертає <code>parent[fieldName]</code>. Тому скалярні поля з рядка БД коду не потребують.	graphql drill02
Why does N+1 happen in GraphQL?	Резолвер поля викликається окремо для кожного батька і не бачить сусідів: 1 запит за списком + N запитів за вкладеним полем.	graphql drill02
What is null bubbling?	Якщо впало non-null поле, null піднімається до найближчого nullable батька. Якщо всі батьки non-null, <code>data: null</code> цілком.	graphql drill03
Nullable vs non-null field: how do you choose?	Non-null там, де значення точно є (id, обов'язкові колонки). Nullable там, де за полем окремий сервіс чи дорога логіка, щоб збій не обнулив увесь екран.	graphql drill03
userErrors vs errors[]: when which?	Очікуване ("виправ поле": валідація, дублікат) повертається даними в <code>payload.userErrors</code> з <code>code</code>. Неочікуване або доступ (auth, 500) іде в <code>errors[]</code> з <code>extensions.code</code>.	graphql drill04
What HTTP status does a GraphQL resolver error return?	Зазвичай 200 з <code>errors[]</code> і частковою <code>data</code>. 400 буває на parse/validate.	graphql drill04
What does DataLoader do?	Батчить усі <code>load(key)</code> за поточний тік в один виклик batch-функції і кешує результат по ключу в межах одного loader.	graphql drill05
When exactly does DataLoader dispatch the batch?	В кінці поточного тіку: <code>Promise.resolve().then(() => process.nextTick(dispatch))</code>. Після вже поставлених мікротасків, до таймерів та I/O.	graphql drill06
What is the batch function contract?	Повернути масив тієї ж довжини, що keys, і <code>result[i]</code> має відповідати <code>keys[i]</code>. Тому мапимо рядки БД через Map назад по keys.	graphql drill05
What happens if the batch function returns rows in DB order?	Помилки немає, дані тихо переплутуються: <code>load(1)</code> отримує чужий рядок. Якщо довжина інша, DataLoader кидає помилку.	graphql drill05
How many SQL does DataLoader produce for posts { author comments { author } }?	Один запит на кожен loader на кожному рівні: posts, users IN, comments IN. Автори коментарів уже в кеші userById, тож 3.	graphql drill07
Can you rely on Prisma's built-in batching instead of DataLoader?	Ні. Prisma батчить тільки findUnique в межах тіку, findMany і вкладені рівні ні. 102 SQL проти 3 у дрілі.	graphql drill07
Why is DataLoader created per request?	Кеш на один запит. Глобальний: витік даних між юзерами (якщо результат залежить від viewer), застарілі дані, ріст пам'яті без меж.	graphql drill13
Why not a JOIN instead of DataLoader?	JOIN добрий, коли форма відповіді відома. У GraphQL форму обирає клієнт, JOIN "на всі випадки" тягне зайве або дає декартів добуток. DataLoader вирішує N+1 для будь-якої форми.	graphql interview
What to do with the loader cache after a mutation?	<code>loader.clear(id)</code> або <code>clear(id).prime(id, updated)</code>, щоб наступні поля в тому ж запиті не отримали старе значення.	graphql drill13
Offset vs cursor pagination?	Offset: простий, але дублі/пропуски при змінах і повільний на великому OFFSET. Cursor: <code>WHERE (created_at, id) &lt; (...)</code>, стабільний і однаково швидкий на будь-якій глибині.	graphql drill08
Why id as a tie-breaker in a cursor?	created_at може збігатися у кількох рядків, і без id межа сторінки відрізає частину групи.	graphql drill16
What is the microsecond trap with created_at cursors?	Postgres зберігає мікросекунди, JS Date тільки мілісекунди. Курсор через Date обрізається, і рядки тихо губляться. Лікування: timestamp(3), курсор рядком або по id.	graphql drill16
How do you get hasNextPage without COUNT?	Запитати <code>first + 1</code> рядків. Якщо прийшов зайвий, наступна сторінка є, а зайвий рядок не віддаємо.	graphql drill08
Where should authorization live in GraphQL?	Біля даних: у сервісі чи резолвері поля, а не на маршруті. Одна операція може зачіпати публічні й приватні поля одночасно.	graphql drill09
What does codegen catch and what not?	Ловить ламаючі зміни: rename, видалення, зміну типу. Не ловить "додав опційне поле і забув використати": це ловить тільки тест.	graphql drill04
What are mappers in graphql-codegen?	Кажуть, що <code>parent</code> у резолверах це рядок БД (Prisma), а не GraphQL-тип. Інакше TS вимагав би, щоб Query.posts одразу повертав авторів.	graphql drill10
Are top-level mutation fields atomic together?	Ні. Виконуються послідовно, але перше закомічене поле не відкотиться, якщо друге впаде. Атомарність = одна мутація з транзакцією всередині.	graphql drill11
Does GraphQL give you transactions?	Ні. Транзакцію відкриває БД всередині резолвера чи сервісу (<code>prisma.$transaction</code>), throw означає ROLLBACK.	graphql drill11
How do you protect against expensive queries?	Depth limit, alias limit, cost limit на етапі validation (0 SQL), плюс обов'язковий ліміт <code>first</code> у сервісі, бо змінні статичним правилам не видно. У проді persisted queries.	graphql drill12
Why is a limit in the resolver mandatory even with a cost rule?	Cost-правило бачить AST, а не значення змінних: <code>posts(limit: $l)</code> з $l = 1e6 пройде validation.	graphql drill12
How do subscriptions scale across instances?	In-memory PubSub бачить тільки свій процес. Для 2+ інстансів потрібен Redis/NATS/Postgres LISTEN/NOTIFY.	graphql drill14
How to load "top N children per parent" in one query?	<code>ROW_NUMBER() OVER (PARTITION BY parent_id ORDER BY ...)</code> і <code>WHERE rn &lt;= N</code>, або LATERAL JOIN. Окремий loader на кожне значення аргументу.	graphql drill15
How to select only requested fields?	<code>info</code> через graphql-parse-resolve-info (фрагменти, aliases). id і foreign keys вибирати завжди, loaders тримати з повними рядками. Варто лише для широких таблиць.	graphql drill17
Does an input default value (= false) replace an explicit null?	Ні. Дефолт спрацьовує, тільки якщо поле не передали. Щоб заборонити null: <code>Boolean! = false</code>.	graphql defaults
Can a field of an output type have a default value?	Ні, тільки аргументи та поля input. Значення поля output-типу завжди дає резолвер.	graphql defaults
