# Learning System

Основа: принципи Ali Abdaal (active recall, spaced repetition, retrospective revision timetable) плюс дріли з репо.

**Три правила, на яких усе тримається**
1. **Питання, а не конспекти.** Конспект відчувається продуктивно, але майже не працює. Замість переписування формулюєш питання і відповідаєш на них з пам'яті.
2. **Складно = правильно.** Повторення має бути зусиллям: порожня сторінка, закрита книга. Перечитування не рахується.
3. **Ретроспективно, а не наперед.** Не планувати "у вівторок тема X", а щоранку дивитись у таблицю і брати найслабше та найдавніше.

## Структура в Notion

Одна сторінка **Learning** з 4 базами даних:

| База | Що в ній | Звідки |
|---|---|---|
| **Topics** | усе, що вчиш: дріли, розділи праймера, AI, Python. Серце системи | імпорт `notion-topics.csv` |
| **Questions** | твої питання до тем + відповідь, написана з пам'яті | заповнюєш сам |
| **Cycles** | двотижневі цикли: ціль, теми, підсумок | 4-5 рядків руками |
| **Inbox** | швидкий запис: ідея, посилання, "не зрозумів X" | телефон або десктоп |

Ali розділяє інструменти так: швидкий запис окремо (у нього Drafts), робоче місце в Notion, картки в Anki. У тебе: Inbox як швидкий запис, Notion як робоче місце, Anki для карток.

### 1. Topics (retrospective timetable)

Імпорт: Notion → Import → CSV → `notion-topics.csv`. Потім змінити типи колонок:

| Колонка | Тип | Значення |
|---|---|---|
| Name | Title | |
| Track | Select | GraphQL, System design, Node, AI, Python |
| Confidence | Select | ⚪ Not started, 🔴 Red, 🟡 Amber, 🟢 Green |
| Last recall | Date | коли востаннє відтворив **з пам'яті** |
| Cycle | Select | 1-5 |
| Drill / file | Text | шлях у репо |
| Source | URL | |
| **Next review** | Formula | див. нижче |
| Questions | Relation → Questions | |

Формула **Next review**:
```
if(empty(prop("Last recall")), today(),
  dateAdd(prop("Last recall"),
    if(prop("Confidence") == "🟢 Green", 21,
    if(prop("Confidence") == "🟡 Amber", 7, 2)),
  "days"))
```

**Представлення (views):**
- **Today:** фільтр `Next review ≤ today` або `Confidence = 🔴`, сортування: спершу червоні, потім найстаріший Last recall. Це екран, з якого починається кожен день.
- **By track:** Board, групування по Track.
- **Cycle now:** фільтр по поточному циклу.

**Кольори (після кожного повторення):**
- 🟢 відтворив з нуля без підказок → інтервал подвоюється (21 → 42 днів: просто пересунь дату вперед);
- 🟡 невеликі прогалини → той самий інтервал;
- 🔴 застряг → звірся з еталоном, повтор через 2 дні.

Last recall міняєш **тільки** після відтворення з пам'яті. Прочитав чи переглянув, не рахується.

### 2. Questions

| Колонка | Тип |
|---|---|
| Question | Title (англійською, як спитають на співбесіді) |
| Topic | Relation → Topics |
| My answer | Text: пишеш **спочатку з пам'яті**, потім звіряєш і доповнюєш |
| In Anki | Checkbox |

Процес на тему (кроки Ali "closed book + questions"):
1. Прочитав або зробив дріл.
2. Закрив джерело і записав 3-5 питань.
3. Відповів з пам'яті в `My answer`.
4. Відкрив джерело і дописав, що пропустив.
5. Найважливіші питання переніс в Anki (`In Anki = ✓`).

### 3. Cycles

| Колонка | Тип |
|---|---|
| Name | "C1 · Node: pool, retries, races" |
| Dates | Date range, 2 тижні |
| Goal | Text: одне речення "після циклу вмію ..." |
| Topics | Relation → Topics |
| Retro | Text: що вийшло, що в червоне |

Цикли: 1 Node (pool, retries, races) → 2 AI/TS (streaming + tools) → 3 AI/TS (RAG + evals) → 4 Python (RAG на FastAPI) → 5 червоні теми з таблиці.
System design не окремий цикл: іде щотижня паралельно (див. нижче).

### 4. Inbox

Одна колонка Title плюс дата створення. Записуєш усе, що спало на думку, не сортуючи. У неділю розбираєш: або в Topics/Questions, або видаляєш.

## Anki

- Імпорт стартової колоди: Anki → File → Import → `anki-graphql.txt` (32 картки з репо: питання англійською, відповіді українською).
- Нові картки роби з бази Questions. **1 картка = 1 думка**, відповідь 2-3 речення своїми словами.
- Стартову колоду варто переписати своїми словами, коли будеш повторювати дріли: власні формулювання запам'ятовуються краще.

## Ритм

**Щодня, ~25 хв**
1. Anki: 10-15 карток.
2. Notion → Topics → **Today**: взяти 1 тему (червону або найстарішу).
3. Відтворити з нуля: дріл на порожньому файлі або пояснення на папері. Звірити, перефарбувати, оновити Last recall.
4. Одне питання з Questions вголос за хвилину.

Ali радить не залипати на одній темі, а робити кілька коротких різних за день (interleaving). Тому щоденне повторення бере з усієї таблиці, а не тільки з поточного циклу.

**Основна робота в будні** йде за поточним циклом і розподілом 50 / 35 / 15.

**Щотижня: system design** ([primer](https://systemdesignschool.io/primer))
- 1 розділ праймера: читаєш, проходиш віджети і квізи, пишеш 3-5 питань у Questions.
- Дріл, якщо розділ його має (у Topics в колонці Drill / file).
- 1 mock: задача 45 хв вголос з таймером (розділ 13, Design Twitter; далі інші).

Порядок праймера: §7 → §8 → §9 → §10 (master template) → §11 по компоненту → §12-13 як навичка → §14 deep dives.

**Неділя, ~20 хв**
1. Розібрати Inbox.
2. Переглянути Topics по треках: що позеленіло, що почервоніло.
3. Записати Retro поточного циклу, якщо він закінчується.
4. Вибрати розділ праймера на тиждень.

## Чого не робити
- Не переписувати відео чи статті в конспект. Тільки питання і відповіді з пам'яті.
- Не ставити 🟢 за "перечитав і все зрозуміло".
- Не брати новий цикл, поки поточний не закінчений.
- Не будувати ідеальний Notion тиждень. Імпортуй CSV, додай формулу і view Today, і вже завтра починай.
